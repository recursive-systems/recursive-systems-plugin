# Security

To report a security concern about the Recursive Systems plugin, the connector it uses
(`https://app.recursivesystems.dev/mcp`) or a Recursive Systems account, email bradley@recursivesystems.dev.

Please say what you found and how to see it again. Never send passwords or sign-in codes, and please don't open a
public issue for a security concern.

The plugin runs no code of its own: it connects Claude to the connector above and adds one skill.

Other help: https://recursivesystems.dev/support/
